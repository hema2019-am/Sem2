3. Aim: Implementing deep neural network for performing classification task.
This program uses a Feed Forward Deep Neural Network to classify breast cancer cases as malignant (0) or benign (1). The built-in Breast Cancer dataset is divided into training and testing data, and StandardScaler is used to normalize the feature values.

The neural network contains two hidden layers with 12 and 8 neurons using the ReLU activation function, while the output layer uses Sigmoid activation for binary classification. The model is trained using the Adam optimizer and Binary Cross-Entropy loss function.

For testing, the program displays 3 samples containing 2 correct predictions and 1 incorrect prediction. Only 5 feature values are displayed for each sample to keep the output simple, although the model uses all 30 features for making predictions.

Term	Explanation
Feed Forward Neural Network	A neural network where data moves in one direction from input layer to hidden layers and then to output layer.
Binary Classification	A classification task with only two possible classes, here malignant (0) and benign (1).
Malignant (0)	Indicates a cancerous tumor.
Benign (1)	Indicates a non-cancerous tumor.
StandardScaler	Standardizes feature values so they have approximately mean 0 and standard deviation 1.
ReLU	An activation function that outputs 0 for negative values and keeps positive values.
Sigmoid	Converts the output into a value between 0 and 1, useful for binary classification.
Binary Cross-Entropy	A loss function that measures the difference between actual and predicted binary classes.
Adam Optimizer	An optimization algorithm that updates model weights to reduce prediction error.

Result: The model successfully classifies breast cancer samples and demonstrates both correct and incorrect predictions on test data.

from keras.models import Sequential
from keras.layers import Dense, Input
from sklearn.datasets import load_breast_cancer
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
import numpy as np

# Load Dataset
data = load_breast_cancer()
X, Y = data.data, data.target

# Split Dataset
X_train, X_test, Y_train, Y_test = train_test_split(
    X, Y, test_size=0.2, random_state=0
)

# Scale Data
scaler = StandardScaler()
X_train = scaler.fit_transform(X_train)
X_test_scaled = scaler.transform(X_test)

# Create Model
model = Sequential([
    Input(shape=(X.shape[1],)),
    Dense(12, activation='relu'),
    Dense(8, activation='relu'),
    Dense(1, activation='sigmoid')
])

# Compile and Train
model.compile(
    loss='binary_crossentropy',
    optimizer='adam',
    metrics=['accuracy']
)

model.fit(
    X_train, Y_train,
    epochs=100,
    batch_size=10,
    verbose=0
)

# Evaluate Model
loss, accuracy = model.evaluate(
    X_test_scaled, Y_test,
    verbose=0
)

print("Accuracy: %.2f%%" % (accuracy * 100))

# Predictions
prob = model.predict(X_test_scaled, verbose=0)
pred = (prob.flatten() >= 0.5).astype(int)

# Find Correct and Incorrect Samples
correct = np.where(pred == Y_test)[0]
incorrect = np.where(pred != Y_test)[0]

# Select 2 Correct + 1 Incorrect
samples = [correct[0], correct[1], incorrect[0]]

# Show 3 Test Samples
print("\n--- Test Samples ---")

for i in samples:

    print("\nTest Data:")

    # Show Only 5 Features
    for name, value in zip(
        data.feature_names[:5],
        X_test[i][:5]
    ):
        print(f"{name}: {value:.4f}")

    result = (
        "Correct"
        if pred[i] == Y_test[i]
        else "Incorrect"
    )

    print("Prediction:", pred[i],
          "-", data.target_names[pred[i]])

    print("Actual:", Y_test[i],
          "-", data.target_names[Y_test[i]])

    print("Result:", result)

5A. Evaluating Feed Forward Deep Network for Regression using K-Fold Cross Validation

This program uses a Deep Feed Forward Neural Network to perform regression and predict continuous diabetes progression values.
The model has two hidden layers with ReLU activation, while StandardScaler standardizes the input data.
The model is evaluated using 10-Fold Cross Validation and MSE, then displays predicted and actual values for 3 test samples.

Term	Explanation
Regression	Predicts continuous numerical values.
StandardScaler	Standardizes input features to a similar scale.
Pipeline	Combines data scaling and neural network training into one process.
K-Fold Cross Validation	Divides data into multiple parts for reliable model evaluation.
10-Fold	Divides the dataset into 10 parts and evaluates the model 10 times.
MSE	Mean Squared Error measures the difference between actual and predicted values.
ReLU	Activation function used in hidden layers.
Adam	Optimizer used to reduce model error.
Result
The Deep Feed Forward Neural Network was successfully evaluated using 10-Fold Cross Validation, and its regression performance was measured using Mean Squared Error (MSE).

from keras.models import Sequential
from keras.layers import Dense, Input
from scikeras.wrappers import KerasRegressor
from sklearn.datasets import load_diabetes
from sklearn.model_selection import cross_val_score, KFold, train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.pipeline import Pipeline

# Load Dataset
data = load_diabetes()
X, Y = data.data, data.target

# Create Model
def wider_model():
    model = Sequential([
        Input(shape=(X.shape[1],)),
        Dense(15, activation='relu'),
        Dense(13, activation='relu'),
        Dense(1)
    ])
    model.compile(loss='mse', optimizer='adam')
    return model

# Create Pipeline
pipeline = Pipeline([
    ('scale', StandardScaler()),
    ('model', KerasRegressor(
        model=wider_model,
        epochs=100,
        batch_size=5,
        verbose=0
    ))
])

# 10-Fold Cross Validation
kfold = KFold(n_splits=10, shuffle=True, random_state=1)

scores = cross_val_score(
    pipeline, X, Y,
    cv=kfold,
    scoring='neg_mean_squared_error'
)

print("Mean MSE:", round((-scores).mean(), 2))
print("Std Dev :", round((-scores).std(), 2))

# Split and Train
X_train, X_test, Y_train, Y_test = train_test_split(
    X, Y, test_size=0.2, random_state=0
)

pipeline.fit(X_train, Y_train)
predictions = pipeline.predict(X_test)

# Show 3 Test Samples
for i in range(3):
    print("\n--- Test Sample", i + 1, "---")

    # Show Only 5 Features
    for name, value in zip(
        data.feature_names[:5],
        X_test[i][:5]
    ):
        print(f"{name}: {value:.4f}")

    print("Predicted:", round(predictions[i], 2))
    print("Actual   :", round(Y_test[i], 2))

This program uses a Feed Forward Neural Network with L1 and L2 regularization for binary classification on the make_moons dataset.
Regularization helps reduce overfitting by adding penalties to large network weights.

Term	Explanation
Binary Classification	Predicts one of two classes: 0 or 1.
Feed Forward Network	Data moves from input to hidden layer and then output layer.

from matplotlib import pyplot
from sklearn.datasets import make_moons
from keras.models import Sequential
from keras.layers import Dense
from keras.regularizers import L1L2

# Generate Dataset
X, Y = make_moons(
    n_samples=100,
    noise=0.2,
    random_state=1
)

# Split Dataset
n_train = 30
trainX, testX = X[:n_train, :], X[n_train:, :]
trainY, testY = Y[:n_train], Y[n_train:]

# Create Model
model = Sequential()

model.add(Dense(
    500,
    input_dim=2,
    activation='relu',
    kernel_regularizer=L1L2(l1=0.001, l2=0.001)
))

model.add(Dense(
    1,
    activation='sigmoid'
))

# Compile Model
model.compile(
    loss='binary_crossentropy',
    optimizer='adam',
    metrics=['accuracy']
)

# Train Model
history = model.fit(
    trainX,
    trainY,
    validation_data=(testX, testY),
    epochs=100,
    verbose=1
)

# Plot Accuracy
pyplot.plot(history.history['accuracy'], label='Train')
pyplot.plot(history.history['val_accuracy'], label='Test')

pyplot.xlabel("Epochs")
pyplot.ylabel("Accuracy")
pyplot.legend()
pyplot.show()

8. Performing encoding and decoding of images using deep autoencoder

This program uses an Autoencoder Neural Network to compress and reconstruct images from the MNIST handwritten digit dataset.
The Encoder compresses each 28×28 image from 784 values to 64 values, while the Decoder reconstructs it back to 784 values.
Finally, the program displays the Original, Encoded, and Decoded images for comparison.

Term	Explanation
Autoencoder	Neural network used to compress and reconstruct input data.
MNIST Dataset	Dataset containing handwritten digit images from 0 to 9.
Encoder	Compresses input data into a smaller representation.
Decoder	Reconstructs the original data from the compressed representation.
Dense Layer	Fully connected neural network layer.
ReLU	Activation function used in the encoder to learn important features.
Sigmoid	Produces output values between 0 and 1, matching normalized pixel values.
Normalization	Converts pixel values from 0–255 into the range 0–1.
Binary Cross-Entropy	Loss function used to measure reconstruction error between original and decoded images.
Original Image	Actual input handwritten digit image.
Encoded Image	Compressed 64-value representation displayed as 8×8.
Decoded Image	Reconstructed image produced by the decoder.
Result
The Autoencoder successfully compresses MNIST images into a smaller 64-value representation and reconstructs them back into 28×28 images for visual comparison.

import numpy as np
import matplotlib.pyplot as plt
from keras.datasets import mnist
from keras.models import Model
from keras.layers import Input, Dense

# Load MNIST Dataset
(x_train, _), (x_test, _) = mnist.load_data()

# Use a smaller dataset for faster execution
x_train = x_train[:2000]
x_test = x_test[:5]

# Normalize images
x_train = x_train.astype("float32") / 255.0
x_test = x_test.astype("float32") / 255.0

# Flatten images
x_train = x_train.reshape((2000, 784))
x_test = x_test.reshape((5, 784))

# ---------------- Encoder ----------------
input_img = Input(shape=(784,))
encoded = Dense(64, activation="relu")(input_img)

# ---------------- Decoder ----------------
decoded = Dense(784, activation="sigmoid")(encoded)

# Autoencoder Model
autoencoder = Model(input_img, decoded)

# Encoder Model
encoder = Model(input_img, encoded)

# Decoder Model
encoded_input = Input(shape=(64,))
decoder_layer = autoencoder.layers[-1]
decoder = Model(encoded_input, decoder_layer(encoded_input))

# Compile
autoencoder.compile(
    optimizer="adam",
    loss="binary_crossentropy"
)

# Train
autoencoder.fit(
    x_train,
    x_train,
    epochs=5,
    batch_size=64,
    shuffle=True,
    verbose=1
)

# Encode Images
encoded_imgs = encoder.predict(x_test, verbose=0)

# Decode Images
decoded_imgs = decoder.predict(encoded_imgs, verbose=0)

# Display Results
plt.figure(figsize=(12,6))

10. Aim: Denoising of images using autoencoder. 

This program uses a Convolutional Autoencoder to remove noise from MNIST handwritten digit images.
Artificial Gaussian noise is added to the original images, and the model learns to reconstruct clean images from noisy inputs.
Finally, it displays the Original, Noisy, and Denoised images for comparison.

Important Terms
Term	Explanation
Autoencoder	Neural network that learns to reconstruct input data.
Denoising Autoencoder	Removes noise and reconstructs a cleaner image.
MNIST	Dataset of handwritten digit images from 0 to 9.
Gaussian Noise	Random noise added to image pixels.
Conv2D	Extracts important image features such as edges and shapes.
MaxPooling2D	Reduces image size and creates a compressed representation.
UpSampling2D	Increases feature-map size during reconstruction.
Encoder	Compresses and extracts important features from the noisy image.
Decoder	Reconstructs the clean image from learned features.
Sigmoid	Produces output pixel values between 0 and 1.
Binary Cross-Entropy	Measures difference between original and reconstructed images.
Result

The Convolutional Autoencoder successfully learns to reduce noise from handwritten digit images and reconstruct cleaner versions of the noisy inputs.

import keras
from keras.datasets import mnist
from keras import layers
import numpy as np
import matplotlib.pyplot as plt

# Load and Normalize Data
(X_train, _), (X_test, _) = mnist.load_data()

X_train = X_train[:5000] / 255.0
X_test = X_test[:5] / 255.0

X_train = X_train.reshape(-1, 28, 28, 1)
X_test = X_test.reshape(-1, 28, 28, 1)

# Add Noise
X_train_noisy = np.clip(
    X_train + 0.5 * np.random.normal(size=X_train.shape), 0, 1
)

X_test_noisy = np.clip(
    X_test + 0.5 * np.random.normal(size=X_test.shape), 0, 1
)

# Create Autoencoder
model = keras.Sequential([
    layers.Conv2D(16, 3, activation='relu',
                  padding='same',
                  input_shape=(28, 28, 1)),

    layers.MaxPooling2D(2, padding='same'),

    layers.Conv2D(16, 3, activation='relu',
                  padding='same'),

    layers.UpSampling2D(2),

    layers.Conv2D(1, 3, activation='sigmoid',
                  padding='same')
])

# Compile and Train
model.compile(
    optimizer='adam',
    loss='binary_crossentropy'
)

model.fit(
    X_train_noisy,
    X_train,
    epochs=3,
    batch_size=128,
    verbose=1
)

# Predict Denoised Images
predictions = model.predict(X_test_noisy)

# Display Results
for i in range(5):

    plt.figure(figsize=(8, 2))

    plt.subplot(1, 3, 1)
    plt.imshow(X_test[i].reshape(28, 28), cmap='gray')
    plt.title("Original")
    plt.axis('off')

    plt.subplot(1, 3, 2)
    plt.imshow(X_test_noisy[i].reshape(28, 28), cmap='gray')
    plt.title("Noisy")
    plt.axis('off')

    plt.subplot(1, 3, 3)
    plt.imshow(predictions[i].reshape(28, 28), cmap='gray')
    plt.title("Denoised")
    plt.axis('off')

    plt.show()
