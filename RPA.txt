Practical 1(a): Create a Simple Sequence-Based Project
Open UiPath Studio.
Click Home → New Project → Process.
Enter the project name and click Create.
Open Main.xaml.
Drag a Sequence activity into the Designer.
Drag two Input Dialog activities inside the Sequence.
Drag one Message Box activity below the Input Dialogs.
Configure the first Input Dialog:
Dialog Title: PrintingNames
Input Label: First Name
Input Type: Text Box
Value Entered: FirstName
Configure the second Input Dialog:
Dialog Title: PrintingNames
Input Label: Last Name
Input Type: Text Box
Value Entered: LastName
In the Message Box, enter: FirstName + " " + LastName
Click Run or Debug File.

Practical 2(a): Count Names Starting with "A"
Open UiPath Studio.
Create a new Process project.
Open Main.xaml.
Drag a Sequence activity.
Create the following variables:
names – Array of String
currentText – String
firstLetter – String
counter – Int32 (Default value = 0)
Add an Assign activity.

Store the array in names.

{"Ajay","Rahul","Anita","Vishal","Aman"}
Drag a For Each activity.
Set Values = names.
Set TypeArgument = String.
Inside the For Each, add an Assign activity.

Assign:

firstLetter = if(String.IsNullOrEmpty(currentText),"",currentText.Substring(0, 1))
Add an If activity.

Set the condition:

firstLetter.ToLower.Equals("a")
Inside Then, add an Assign activity.

Increment the counter:
counter = counter + 1
Inside Else : 
Add Write Line : with text "Name doesn't start with a:   "+ currentText
After the For Each, add a Message Box.
Display:
"Total names starting with A : " + counter.ToString
Click Run.
